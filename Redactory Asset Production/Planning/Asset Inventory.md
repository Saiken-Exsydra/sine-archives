# Redactory Asset Inventory

First pass for the Redactory Academy Experience Lab. Image links open the local source for preview. Roles come from folder names, filenames, and the website references cited below. The dimensions and alpha-channel flags come from file metadata.

Permission for reuse, editable master availability, and approval for Lab publication are unverified for every entry. Existing site use is recorded separately from Lab approval. An alpha channel indicates that the format can carry transparency.

## Start here

- **SiNE identity.** Start with the site-used ui-sine-logo.png and compare it with the homepage-named and large variants.
- **Redactory and the Academy.** Review Redactory Logo.png, the white Redactory symbol used on the site, Apocachynthion.png, sys-redactory-panel.png, and Index Theorem.png.
- **Anchor artwork.** The Redactory site data identifies separate seal and symbol files for Shallow, Deep, and Abyssal. Review the forms side by side before choosing where each belongs in the Lab.
- **Lesson props.** The current site lists desk, paper, inkpot, and quill-gateway artwork. These are candidates for a reading panel or teaching desk.

**Author review.** No file in the Icons folder explicitly names the standalone Wonderwall family mark. Please identify the approved file if you recognize it. The filenames also leave the preferred roles of Redactory.png and Redactor.png open.
