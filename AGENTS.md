# SiNE Archives React Reconstruction

Build the React successor to the full SiNE Archives site on `experiment/react-systems`. Use the live Astro site on `main` as a reference during the gradual reconstruction. Prefix commits on this branch with `[CF-Pages-Skip]`.
Make reconstruction changes in this checkout (`React-Systems`). The sibling `../SiNE Archives REPO/` is a separate clone of the same repository. Read its local files for context. For the exact committed version on `main`, use the Git command in the README, regardless of which branch the sibling has checked out.
Read and follow the [Imperial Obsidian design philosophy](DESIGN_PHILOSOPHY.md) before changing the interface. For interface work, use the [four Pearl Spectrum precedents](DESIGN_PHILOSOPHY.md#pearl-spectrum-in-practice) and their shared optical styles. Adapt the treatment to the component within the current task. Pearl Spectrum Phase V was cancelled. Dedicated Redactory and other Systems pages await a separate development request.
For animation work, start with the [motion architecture and source map](MOTION_ARCHITECTURE.md). Reuse the global Motion provider and shared tokens. When changing the landing ripple, review both the WebGL crest and its CSS fallback against the same single-wave composition. Keep the timing score and replay instructions current when behavior changes.
Find current logo masters and House specifications under `Artworks/Design Systems` in the configured Archive. Use the existing approved corporate copies in `src/art/` and the asset pipeline for new publication symbols. See README.md for digital palette roles.
When introducing website imagery, consult the [SiNE Asset Pipeline](ASSET_PIPELINE.md) first. Use its approvals, profiles and shared React delivery API for publication imagery. Coordinate environment changes with decoded artwork and keep section navigation independent of the image lifecycle.
Use the [Google Drive source folder](https://drive.google.com/drive/folders/1FE6HmV2ajz02Or79rc95Nyd-A8wmICrN) when extracting text for new designs. Check the original passage when revising an extract.
Follow the [character publication workflow](CHARACTER_PUBLICATION.md) for new editions, retcon reconciliation, translation updates and freshness investigations. Treat investigation as read-only and prepare editions in a private copy outside this checkout. Read the Archive authoring standard and the current governing sources. Obtain explicit approval of the exact examination and Complete Dossier editions by language before promoting them or recording a reviewed revision. Obtain separate authorization before committing, pushing, deploying or editing canonical sources.
Every new character entry must include an English Complete Dossier, which both interface languages open. Derive Overview, Biography, Abilities and Relations from the dossier and governing sources. Review the dossier alongside the examination and hold promotion until both have an approved edition.
Preserve public canon and locale-specific wording. Use addressable routes, keyboard focus, full-motion transitions with reduced-motion support, and effect cleanup.
Use the root `Start-React-Systems.cmd` launcher and Zen Browser for live local verification. Use `http://localhost:5174` for all local review, including staged character editions under `/__review/`. Validate with `npm run build` and `npm test`. The Chromium tests load the built files without starting a server.
